This is Vigaash's personal website, a website that is all about me. Dive in to learn all about yours truly!

Here is the demo link: https://vigaash-lingeswaran.github.io/Personal-Site/
I would recommend using the website with a 75% zoom for the best experience!

Features:
- Home Screen: The home screen that tells the viewer all about Vigaash and his interests. It is also where all of the navigating systems are.
- Projects Page: This is the page where you can see all of Vigaash's projects and try them out!
- Interests: This is the page where you can see all of Vigaash's interests!
- Changing Background: This is a feature where the background alternates between images!

Building Notes:
The Code: the code used in this project was HTML, Javascript and CSS. HTML was used for all of the main pages and buttons (divs, heade,s. and more). Javascript was used for certain actions (live time element). CSS was used for the styles (font-size, and more).
The Images: All of the images and the icons that were used were free-use images. 

Running it Locally:
1. Clone this repository
2. Open the cloned folder
3. Open the folder in your editor, and you will have access to all three of the files (index.html, script.js, and styles.css)
4. From there, you can edit whatever things you would like!
