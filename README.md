Features:

- Projects Page: This is the page where you can see all of Vigaash's projects and try them out!
- Interests: This is the page where you can see all of Vigaash's interests!
- For Professors: This is just a page for some professors to see some of my past experiences!
- Changing Background: This is a feature where the background alternates between images!

Building Notes/Tech Stack:
- The Code: the code used in this project was HTML, Javascript and CSS. HTML was used for all of the main pages and buttons (divs, headers. and more).
- Javascript was used for certain actions (live time element).
- CSS was used for the styles (font-size, and more).
- The Images: All of the images and the icons that were used were free-use images.

Problems and Solutions
- Spacing Issues: One problem with all of the different Divs, headers, and more all had a very common problem. It would always seem somehow off center itself, even though I had put those details in the styles files. After a lot of frustration, I decided to just use the transform() function, which allowed me to exactly place whatever components I needed.
- Photo carousel: This was a problem on the Interests page, as I wanted to show the user all of the photos of my robotics projects, but didn't want to make a collage. In order to combat this, I wanted to make a carousel. At first, I thought I could make a function that would cycle all of the photos. That was only the first part. After some research, I decided to put all of the images into an array, which would then be cycled through every time a button was pressed.
- Background Changing: This problem was kind of similar to the photo carousel, but was a little different. This time, I would have to make the photos automatically change after a certain amount of time. This meant that I was still going to be using an array of photos, but would have to modify another part. I knew there needed to be a timer, but I didn't know how to implement it. After some research online, I figured that people like to use the setInterval() command for this. After using this, I was able to input the amount of time each photo stayed for, and I was able to solve the problem.

Running it Locally:
1. Clone this repository
2. Open the cloned folder
3. Open the folder in your editor, and you will have access to all three of the files (index.html, script.js, and styles.css)
4. From there, you can edit whatever things you would like!
